# Stillhaus — concept brand and website

A spec / portfolio project: brand identity, website templates and campaign assets for a fictional
collection of small houses in the Alps and the Nordic countries. Stillhaus, its houses, prices and copy are invented.

- Live: https://ksiva.github.io/stillhaus-concept/
- Brand book and campaign assets: https://ksiva.github.io/stillhaus-concept/brand/
- Templates: home, house index with filters, house page, editorial article, paid-traffic landing page,
  600 px email, display banners (HTML5) and paid-social formats.
- Stack: Astro 7 (content collections), GSAP ScrollTrigger for motion, self-hosted OFL fonts
  (Archivo, Newsreader). Respects `prefers-reduced-motion`.
- Photography: Unsplash, Unsplash License; per-photo sources on the credits page.
